# 01. Виртуальная машина и установка РЕД ОС 8

Документ для человека, который ставит ОС на ВМ впервые. Команды копируйте целиком.

## 1. Что такое ВМ

Виртуальная машина (ВМ) — «компьютер внутри компьютера». На гипервизоре (ESXi, Hyper-V, VirtualBox) создаётся ВМ, в неё ставится РЕД ОС 8, туда же ставится NovaTIP.

## 2. Рекомендуемые параметры ВМ

| Параметр | Минимум | Рекомендуется |
|---|---|---|
| vCPU | 2 | 4 |
| RAM | 4 ГБ | 8 ГБ |
| Диск | 40 ГБ | 80–100 ГБ SSD |
| Сеть | 1× NAT или Bridged | Bridged / VLAN с доступом в интернет (для обновлений и NVD) |
| Гостевая ОС | РЕД ОС 8 x86_64 | РЕД ОС 8 x86_64 |

## 3. Создание ВМ (кратко)

### 3.1. VMware ESXi

1. Host → **Create / Register VM**.
2. Имя: `novatip-prod`, Guest OS: Linux / Other Linux 5.x (64-bit) или Red Hat-compatible.
3. CPU/RAM/Disk — по таблице выше.
4. Сеть: VM Network / нужный порт-групп.
5. CD/DVD: Datastore ISO → ISO РЕД ОС 8.
6. Finish → Power on.

### 3.2. VirtualBox (для домашнего стенда)

1. **Создать** → имя `novatip`, тип Linux, версия Red Hat (64-bit).
2. Память ≥ 4096 МБ, диск ≥ 40 ГБ (VDI, динамический).
3. Настройки → Носители → Optical → выбрать ISO РЕД ОС 8.
4. Сеть: **Сетевой мост** (Bridged) или NAT + проброс портов 22/443.
5. Запустить ВМ.

### 3.3. Hyper-V

1. New → Virtual Machine → Generation 2 (или 1, если ISO того требует).
2. Memory 4096+, Dynamic Memory по желанию.
3. Network: External switch.
4. Connect ISO, Start.

## 4. Скачивание ISO РЕД ОС 8

1. Откройте сайт вендора РЕД СОФТ / портал загрузок вашей организации.
2. Скачайте **РЕД ОС 8** (x86_64), формат ISO.
3. Проверьте контрольную сумму (если указана на сайте):

```bash
sha256sum redos-8-*.iso
```

Ожидаемый вывод: длинная hex-строка, совпадающая с опубликованной.

## 5. Установка ОС (пошагово в инсталляторе)

1. Выберите язык интерфейса: **Русский**.
2. Раскладка клавиатуры: RU + EN.
3. Часовой пояс: ваш регион; включите NTP, если есть пункт.
4. Разметка диска:
   - **Новичок:** одна точка монтирования `/` на весь диск (проще).
   - **Рекомендуется для боя:** `/` (20+ ГБ), `/var` (20+ ГБ), `/opt` (20+ ГБ), `swap` ≈ RAM.
5. Hostname: например `novatip.example.local`.
6. Задайте пароль **root** (запишите в сейф).
7. Создайте обычного пользователя (например `admin`) с правами администратора / sudo, если мастер предлагает.
8. Сеть:
   - **DHCP** — если адрес выдаёт ваша сеть.
   - **Статический IP** — укажите IP, маску, шлюз, DNS (например `8.8.8.8` или корпоративный).
9. Дождитесь установки → **Перезагрузка** → извлеките ISO из ВМ.

## 6. Первый вход и обновления

1. Войдите как пользователь с sudo или как `root` на консоли.
2. Обновите систему:

```bash
sudo dnf -y update
```

Ожидаемо: пакеты скачиваются и ставятся, в конце `Complete!`.

3. Установите и включите NTP (`chrony`):

```bash
sudo dnf -y install chrony
sudo systemctl enable --now chronyd
chronyc tracking
```

Ожидаемо: строка с `Reference ID` / `Leap status: Normal`.

4. Задайте hostname (если не задали в инсталляторе):

```bash
sudo hostnamectl set-hostname novatip.example.local
hostnamectl
```

## 7. Пользователь с sudo и SSH

1. Создайте пользователя (если ещё нет):

```bash
sudo useradd -m -G wheel deploy
sudo passwd deploy
```

2. Проверьте sudo:

```bash
su - deploy
sudo id
```

Ожидаемо: `uid=0(root)` в выводе `sudo id`.

3. С Windows подключайтесь по SSH:
   - **Windows Terminal / PowerShell:** `ssh deploy@IP_ВМ`
   - **PuTTY:** Host = IP ВМ, Port 22, Open.

Узнайте IP на самой ВМ:

```bash
ip -4 addr show
```

## 8. Проверка сети

```bash
ping -c 3 $(ip route | awk '/default/ {print $3}')
ping -c 3 8.8.8.8
getent hosts ya.ru || getent hosts example.com
```

Если ping шлюза не проходит — проверьте кабель/виртуальный свитч и IP.  
Если шлюз пингуется, а DNS нет — исправьте `/etc/resolv.conf` или настройки NetworkManager.
