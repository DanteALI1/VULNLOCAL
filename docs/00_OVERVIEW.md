# 00. Обзор NovaTIP

NovaTIP — локальная платформа учёта уязвимостей (Threat Intelligence Platform) для установки на сервер организации.

## 1. Что умеет система

1. Каталог уязвимостей из источников **NVD**, **KEV (CISA)** и **БДУ ФСТЭК**.
2. Локальные карточки с префиксом организации, например `ACME-2026-0001`.
3. Заявки на устранение со строгими переходами статусов и ролями.
4. Мастер первой настройки, лицензирование, уведомления (почта / Telegram).

**Wiki / NovaWIKI в продукте нет и не планируется.**

## 2. Куда что ставится (схема)

```text
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  Браузер    │────▶│  Nginx+TLS   │────▶│  Gunicorn   │
│  админа     │     │  :443        │     │  Django     │
└─────────────┘     └──────────────┘     └──────┬──────┘
                                               │
                    ┌──────────────┐            │
                    │ PostgreSQL   │◀───────────┤
                    │ :5432        │            │
                    └──────────────┘            │
                    ┌──────────────┐            │
                    │ Redis        │◀───────────┤
                    │ Celery       │◀───────────┘
                    └──────────────┘
```

| Компонент | Назначение | Типичный путь / порт |
|---|---|---|
| РЕД ОС 8 | Операционная система ВМ | — |
| PostgreSQL 16 | Основная БД | `127.0.0.1:5432` |
| Redis 7 | Очереди Celery | `127.0.0.1:6379` |
| Python 3.12 + venv | Приложение NovaTIP | `/opt/novatip` |
| Nginx | TLS и reverse proxy | `:443` → Gunicorn |
| systemd | Автозапуск web/worker/beat | `novatip-*.service` |

## 5. Важные термины

1. **УЗ PostgreSQL** — пользователь базы данных (`novatip` в SQL). Это **не** логин в веб-интерфейс.
2. **Администратор NovaTIP** — учётная запись веб-консоли (создаётся на шаге 5 мастера).
3. **Grace-лицензия** — 14 дней работы без online-проверки / в dev-режиме.
4. **Sync** — синхронизация каталога; настраивается во вкладке **Настройки → Источники / Sync**, не отдельным пунктом меню.
